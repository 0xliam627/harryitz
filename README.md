# harryitz

Website profile cá nhân tĩnh của Nguyễn Viết Hiếu.

## Chạy local

```bash
python3 -m http.server 8000
```

Mở `http://localhost:8000/`.

## Kiểm tra

```bash
python3 verify.py
```

## Cập nhật nội dung

- Hồ sơ, dự án, liên hệ: `index.html`
- Bài PMMP: `writing/pmmp.html`
- Giao diện: `site.css` và `tokens.css`
- Ảnh chân dung website: `assets/nguyen-viet-hieu.jpg`
