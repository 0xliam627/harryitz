# harryitz — Portfolio

Trang web cá nhân hiện đại và tối giản của **Nguyễn Viết Hiếu (harryitz)** — Full-Stack Developer & Freelancer tại **@TwoTech Studio**.

🌐 **Domain:** [harryitz.me](https://harryitz.me)

## 🚀 Công nghệ sử dụng

- **Core:** React 19 + TypeScript + Vite 8
- **Styling:** Tailwind CSS v4
- **3D Graphics:** Three.js (Interactive particle constellation & responsive camera tracking)
- **Kinetic Animations:** GSAP (Typography reveals & kinetic motion)
- **Interactions & Transitions:** Framer Motion (Page switching, layout morphing, modal overlays)
- **Icons:** Lucide React & Custom Brand Vectors
- **Confetti Effects:** Canvas Confetti

## 🛠️ Hướng dẫn phát triển (Local Development)

```bash
# Cài đặt dependencies
npm install

# Chạy development server
npm run dev

# Mở trình duyệt tại http://localhost:5173
```

## 📦 Đóng gói & Triển khai (Build & Deploy)

```bash
# Build production tĩnh
npm run build

# Xem thử bản build
npm run preview
```

Dự án đã tích hợp sẵn GitHub Actions workflow tại `.github/workflows/deploy.yml` tự động build và deploy lên GitHub Pages khi push vào nhánh `master`.
